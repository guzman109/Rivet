# Changelog

## 0.1.3 — 2026-10-16

### Added

- Fish, Bash (including macOS Bash 3.2), and Zsh completions via `rivet completions SHELL`, sharing command and option definitions with CLI help.
- Grouped command overview and focused `rivet help COMMAND` / `rivet COMMAND --help` references.

### Changed

- Apply Rivet’s maroon Catppuccin palette throughout terminal help, previews, prompts, diagnostics, and task summaries. Support light/dark palettes, automatic terminal detection, `NO_COLOR`, and explicit color overrides.
- Present CLI errors without internal Lua assertion locations.

### Compatibility and updates

- Requirements remain Neovim 0.11+ on macOS or Linux; the optional CLI requires Lua 5.1+ or LuaJIT. Built-in `vim.pack` requires Neovim 0.12+.
- Update through your plugin manager, restart Neovim, and rerun `:RivetInstallCLI` if the command link points to an older plugin installation.
- Fish, Bash, and Zsh completion scripts are generated by the installed CLI; regenerate saved scripts after updating Rivet.

## 0.1.2 — 2026-10-16

### Added

- `:RivetInstallCLI` / `:Rivet install-cli` links the installed plugin's CLI into `~/.local/bin`, with PATH and Lua runtime guidance. The Lua API accepts a custom directory. Repeated installation is safe, and existing files or unrelated symlinks are preserved.
- Installation instructions for using the CLI from a terminal after installing the Neovim plugin. Symlinks follow plugin updates; moving or removing the plugin requires removing the old link.

### Compatibility and updates

- Requirements remain Neovim 0.11+ on macOS or Linux, plus Lua 5.1+ or LuaJIT for the CLI. Built-in `vim.pack` requires Neovim 0.12+.
- Update through your plugin manager, restart Neovim, and run `:RivetInstallCLI` once. Add `~/.local/bin` to your shell PATH if needed. Review `:RivetUpgrade` separately for project templates.
- C++ `import std` requires CMake 4.4.0–4.4.4 and a compatible compiler/standard library. GPU starters require their matching SDK and hardware; CI does not certify GPU runtime support.

## 0.1.1 — 2026-10-15

### Changed

- Prioritize header personalization and Doxygen documentation in Neovim's C/C++ creation wizard when no header style is saved. Saved identity and project styles retain priority, and No header remains available.
- Recognize C/C++ header and module filenames when selecting the Doxygen header style without an explicit language.
- Reorganize the documentation into tutorials, how-to guides, reference, and explanation; improve article width and keep option labels together.
- Publish the website through Cloudflare Workers Builds while GitHub Actions runs the repository checks.

### Compatibility and updates

- Requirements remain Neovim 0.11+ on macOS or Linux; the optional portable CLI requires Lua 5.1+ or LuaJIT. Built-in `vim.pack` installation requires Neovim 0.12+.
- Existing manifests, CLI header defaults, and other languages keep their current behavior. Update through your plugin manager and restart Neovim; review `:RivetUpgrade` separately for project templates.
- C++ `import std` requires CMake 4.4.0–4.4.4 and a compatible compiler/standard library. GPU starters require their matching SDK and hardware; CI does not certify GPU runtime support.

## 0.1.0 — 2026-10-13

First public release of Rivet.nvim, formerly Outset.

### Added

- Reviewed project creation and native tasks for C++, C, Python, Rust, SwiftPM, and Lua, from Neovim or the optional Lua CLI.
- C++17–26 projects with separate choices for headers, named modules, module layout, and standard-library modules; optional HPC and graphics workload starters.
- File creation asks for the language and template. Source/header pairs, module interface/implementation pairs, mixed C files, and foreign-language files have explicit reviewed plans.
- Lua applications, libraries, and Neovim plugins with Lua, LuaJIT, or Neovim runtime selection, syntax checks, tests, optional formatting/linting, and script/module templates.
- Opt-in Lua embedding examples for C/C++ and Rust, with reviewed host build/dependency changes. Files-only Lua scripting adds no runtime dependency.
- `:RivetConfig` / `rivet config`: explained common clang-format, clang-tidy, and clangd settings, installed-tool validation, and YAML access for advanced options.
- `:RivetUpgrade` / `rivet upgrade`: supplementary template updates using recorded baselines, local-edit preservation, missing-file restoration, and reviewed version metadata.
- Retained output per project, visible task controls, Enter to close completed output, `:RivetOutput`, `:RivetStop`, and optional `task_output = 'close-on-success'`.
- A first-project walkthrough for every language, Doxygen API documentation/HTML/XML guidance, and file-template header previews.
- Neovim help, provider interfaces, documentation, license templates, and reviewed Outset migration.

### Fixed

- Preserve private/executable file permissions during replacements and moves.
- Prevent project modules from shadowing Python test/syntax-check tools and falsely reporting success.
- Keep Python Doctor probes independent of project files that shadow optional tools.
- Preserve C++ raw-string contents during module renames.
- Keep another project's running output and stop controls available.
- Complete tasks and retain raw output when a provider renderer or diagnostic hook fails.
- Preserve Cargo application JSON after build completion and reject ambiguous workspace binary names.
- Resolve embedded Lua modules from the project checkout, including when launched from another directory.
- Match file previews to generated headers, including mixed-language files and custom preview callbacks.
- Pass the selected configuration to multi-configuration CTest fallback tasks.
- Reject unknown C/Swift file targets and conflicting scaffold names.
- Format added C++ files using the current project `.clang-format`.
- Recognize quoted/commented clangd database paths.
- Keep technical documentation search terms unchanged by browser autocorrect.

### Compatibility and updates

- Neovim 0.11+; built-in `vim.pack` installation needs Neovim 0.12+. macOS and Linux are supported.
- The optional CLI needs Lua 5.1+ or LuaJIT. Release assets contain portable source, not a compiled executable.
- Install language tools explicitly. Lua embedding requires Lua development libraries for C/C++; Rust's pinned vendored `mlua` dependency may download crates during the first build.
- GPU examples need their matching SDK/hardware; CI does not certify GPU runtime support.
- Update Rivet through the plugin manager, restart Neovim, then review `:RivetUpgrade` separately in each project. Older manifests without baselines retain unverifiable local files.
- `require('outset')` and `bin/outset` remain deprecated compatibility shims until 0.3.0. Legacy projects use `:RivetMigrate` before normal Rivet operations.
